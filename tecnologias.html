Tecnologías que estamos aprendiendo

Durante la carrera utilizamos diferentes tecnologías y herramientas que permiten desarrollar páginas web, aplicaciones y proyectos de software.

Principales tecnologías

HTML

HTML permite crear la estructura y el contenido de las páginas web.

CSS

CSS permite aplicar estilos, colores, tamaños y diferentes diseños a las páginas web.

JavaScript

JavaScript permite agregar programación e interacción a las páginas y aplicaciones web.

Herramientas

  • Visual Studio Code
  • Git
  • GitHub
  • Node.js
  • MySQL

Desarrollo web

Diseño

Utilizamos HTML y CSS para construir la estructura y presentación visual de los sitios web.

Programación

Utilizamos JavaScript para trabajar con datos, funciones, eventos y diferentes comportamientos.

Mi aprendizaje

El aprendizaje de estas tecnologías permite comprender cómo se construyen los sitios web y desarrollar proyectos cada vez más completos.
