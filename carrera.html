Mi carrera

Actualmente estoy cursando la Tecnicatura Superior en Desarrollo de Software Full Stack. La carrera está orientada al aprendizaje de diferentes herramientas y conocimientos necesarios para desarrollar aplicaciones y sitios web.

Áreas de formación

Frontend

Aprendemos a crear la parte visual de las aplicaciones utilizando HTML, CSS y JavaScript.

Backend

Trabajamos con la programación del lado del servidor, los datos y la lógica de las aplicaciones.

Bases de datos

Aprendemos a organizar, almacenar y consultar información utilizando bases de datos.

Objetivos de la carrera

El objetivo es adquirir conocimientos de programación, desarrollo web, bases de datos y otras herramientas relacionadas con el desarrollo de software.

También se busca desarrollar la capacidad de resolver problemas y trabajar en proyectos tecnológicos.

Mi objetivo personal

Mi objetivo es adquirir los conocimientos necesarios para desarrollarme profesionalmente en el área de tecnología y continuar aprendiendo nuevas herramientas.
